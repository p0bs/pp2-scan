## Predicting this season’s Premier League

This site contains results from our calculations on each team’s chances
in the Premier League this season. (For example, the chance of winning
the title, being in the Champions League next year or being relegated.)

In each case, we also consider the impact of each team’s next game on
these chances. As a result, our results show the current chance of each
event and three extra scenarios:

- What that chance would be if the team won its next game
- What that chance would be if the team drew its next game
- What that chance would be if the team lost its next game

Specifically, we create:

- An <a href="https://p0bs.github.io/pp2-scan/table.html"
  target="_blank">interactive table</a> of these chances

- A <a href="https://p0bs.github.io/pp2-scan/chart.svg"
  target="_blank">static plot</a> of these chances

- An <a href="https://p0bs.github.io/pp2-scan/echart.html"
  target="_blank">interactive version</a> of the static plot, where you
  can hover over the points to get more information

All this will soon form part of a dedicated website that will include
far more details. Stay tuned!
